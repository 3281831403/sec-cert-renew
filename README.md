证书自动续期跑完之后，旧证书被立刻吊销，可新证书还没分发下去，服务中断了十分钟：续期必须在证书到期前的策略窗口内触发；新旧证书之间要有并行期，旧证书在并行期内仍然有效；并行期长度由策略给出；续期请求必须复用同一主体与密钥，或者在策略要求时更换密钥；同一证书的重复续期必须幂等，重复请求只能得到同一张新证书；续期失败不得影响现有证书；批量续期时每张证书各自独立。系统必须始终满足两条不变量：同一证书重复续期得到一致结果；并行期内新旧证书都能通过校验。
